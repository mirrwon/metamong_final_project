## 기본규칙 ##

00. App.js
- path = 홈페이지 주소명
- element = import 명

01. useNavigate
- 네비 명칭 => nav 로 통일

02. 함수명칭 동사로 사용
- onSubmit
- handleSubmit
- goHome
- goLogin

03. 호출함수명 앞에 +Join 넣어주기
- Register 페이지에서 로그인관련 코드 폼 명칭 +Join 넣어서
=> JoinRegister

04. 1:1연결 / 재사용 경로 명확
- components => auth / common / layout
auth = 인증관련 (회원가입, 로그인)
common = 재사용 (버튼)
layout = 화면단 (Header, Footer, Sidebar)

- Login 페이지를 만든다.
ex) Login => pages/auth/Login.js 
    JoinLogin => components/auth

05. 명칭 주석달기
- App.js 기준설명
=> import, Route 부분에 어떤것인지 명칭 주석달기. / + 물어보기쉽게 이름까지

06. console.log 지우기
- 확인 후 console.log 구문 꼭 없애기.

07. axios, API 호출
- API 호출관련 명령어는 services/api.js , authService 참조.
